# 雨天跳跳排行榜設定

網站在尚未連接 Google Sheet 時，會先使用瀏覽器的本機排行榜。完成以下設定後，所有玩家才會共用同一份排行榜。

1. 建立一份新的 Google Sheet，例如「水窪跳跳排行榜」。
2. 在試算表開啟「擴充功能 → Apps Script」。
3. 刪除編輯器內的範例程式，貼上 `panda-rain-leaderboard.gs` 的全部內容並儲存。
4. 點選右上角「部署 → 新增部署作業」。
5. 類型選擇「網頁應用程式」；執行身分選「我」，存取權選「任何人」。
6. 完成 Google 授權後，複製結尾為 `/exec` 的網頁應用程式網址。
7. 將網址提供給網站維護者，設定成建置變數 `NEXT_PUBLIC_PANDA_RAIN_LEADERBOARD_URL` 後重新發佈網站。

第一次讀取或送出成績時，Apps Script 會自動建立 `PandaRainScores` 工作表；不需要手動建立欄位。

往後若修改 Apps Script，請在「管理部署作業」建立新版本並更新現有部署，網址可保持不變。
